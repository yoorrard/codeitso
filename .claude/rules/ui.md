# 화면 규칙 (Astro + Preact 섬)

명세: `docs/UX.md`(화면·모션·접근성), `docs/DESIGN.md`(디자인 의뢰서), `docs/ARCHITECTURE.md`(라우트·저장·공유·성능).

## 구조

- 화면은 `evaluate(catalog, session)` 결과를 **보여 주기만** 한다. 점수·충돌·순서 계산을 화면에서 하지 않는다 (필요하면 엔진에 함수를 더한다).
- 상태 저장은 `src/lib/store.ts` 한 곳. 계산 결과는 저장하지 않고 매번 `evaluate`. 저장은 `r.session`으로.
- 섬(Preact)은 상태가 필요한 곳에만. 나머지는 정적 Astro. 섬은 `client:visible`/`client:idle`을 먼저 생각하고, 첫 화면에 꼭 필요한 것만 `client:load`.
- 문구는 `src/copy/ko.ts`, 엔진 문장은 `data/templates.json`. 화면 코드에 한국어 문장을 쓰지 않는다 (품질 바닥선 검사가 막는다).
- 외부 주소에서 자원(스크립트·스타일·글꼴·그림)을 불러오지 않는다. 화면에서 부르는 API는 `/api/event` 하나뿐.

## 모양

- 색·글꼴·크기·모서리·그림자·모션 길이는 `src/styles/tokens.css` 변수만. 새 값이 필요하면 토큰을 먼저 더하고 대비를 검사한다.
- 휴대폰 360px 기준, 양옆 `--gutter`(20px, 359px 이하 16px), 읽는 폭 640px. 주 버튼은 아래 엄지 자리, 화면마다 하나. 누르는 곳 44×44px 이상.
- 색 문법 (docs/review/v2/brief.md 4.1): 남색 = 내 것(고른 것·지나온 길·브랜드 면), 파랑 = 지금·할 일(주 버튼 `--accent`, 초점, 링크), 청록 = 빛(남색 위 점·길의 심). 금색은 쓰지 않는다. `--brand-blue`(#0082FA)와 `--cyan`은 흰 바탕의 글자색으로 쓰지 않는다(그림 전용, 청록 글자는 남색 위에서만). `--warn` 채움 위 글자는 `--on-warn`.
- 카드 안에 카드를 두지 않는다. 2px 진한 테두리와 외곽선 버튼을 쓰지 않는다. 64px 넘는 그림은 옅은 판(`--plate`)에 그린다.
- 사람 캐릭터 그림은 쓰지 않는다 (D56). 예외는 소유자 로고 하나이고(D60), 로고는 표정·자세를 바꾸거나 빈 상태·오류 화면에 넣지 않는다. 그림은 CONCEPT 5·9절 체계: 평면 SVG 지도 + 청사진 선 그림(`svg-illustrator`) + 소유자 원본을 `npm run art`로 같은 조명에 구운 미니어처 렌더. 지도 위에는 위에서 본 그림만, 3/4 렌더는 지도 밖에만.
- 주소는 `src/lib/routes.ts`에서 가져다 쓴다 (화면 코드에 '/destination' 같은 주소를 쓰지 않는다).

## 접근성 (WCAG 2.2 AA)

- 키보드만으로 끝까지. 초점 테두리 늘 보임. 화면이 바뀌면 제목으로 초점, `<title>` 바꿈.
- 인터뷰 보기는 버튼 + `aria-pressed` (라디오 금지, D19).
- 결과(복사·담기·충돌 해결)는 `aria-live`로. 옆 창·아래 창은 초점 가두기 + Esc + 닫으면 원래 자리.
- 색만으로 뜻을 전하지 않는다. 글자 200%에서 잘리지 않는다.

## 모션

- `game-motion`·`animate` 스킬을 따른다. 모션 하나 1초 안쪽, 장면 3초 이하, 누르면 끝, 동작 줄이기(기기·사이트 둘 다)에서 이동 없음.
- 길이는 숫자로 쓰지 않고 토큰(`var(--dur-…)`, TS에서는 `dur()`).

## 확인

화면을 바꾸면 `/visual-qa`로 360·768·1280px와 동작 줄이기 스크린샷을 찍어 **직접 보고**, axe 심각·치명 0, 예산 통과를 확인한다.
