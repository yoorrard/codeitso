# 코드쇼퍼 (Code Chauffeur)

> 어디로 모실까요? 요금은 0원입니다.
> 코드는 몰라도 됩니다. 목적지만 말하세요.

바이브코딩 초심자가 질문에 답하고 필요한 재료를 골라 담으면, 자기 AI에 넘길 **설계 꾸러미**와 **대화 카드**, 먼저 알아 둘 **공부할 것**, 직접 확인할 **조사할 것**을 영수증처럼 받아 가는 무료 웹 서비스입니다. 사이트는 AI를 쓰지 않고 공개된 규칙으로 판단하며, 운영비는 월 0원으로 시작합니다.

이 폴더는 Claude Code에 넣어 바로 구현을 시작할 수 있게 만든 **개발 꾸러미**입니다.

## 이 꾸러미에 든 것

| 경로 | 내용 | 상태 |
|---|---|---|
| `CLAUDE.md` | Claude Code가 매번 읽는 규칙 | 완성 |
| `.claude/rules/` | 파일 종류별 규칙 (자료, 엔진, 화면, 문장) | 완성 |
| `.claude/skills/` | `/next-task`, `/add-product`, `/verify` | 완성 |
| `docs/` | 요구사항, 작업 목록(T01~T22), 구조, 엔진 명세, 자료 안내, 화면 설계, 영수증 형식, 결정 기록 | 완성 |
| `src/lib/engine/` | 판단 엔진: 인터뷰 → 장보기 추천 → 재확인 충돌 → 영수증·설계 꾸러미 | 완성, 검사 통과 |
| `data/` | 씨앗 자료: 질문 14개, 상품 19개, 규칙 35개, 개념 카드 10장, 조사 카드 13장, 레시피 5개, 에러 안내 6개, 골든 사례 15개 | 완성 (진열 상품 16개는 사람 확인 필요) |
| `schemas/` | 자료 스키마 | 완성 |
| `scripts/` | 자료 검사, 골든 사례 검사, 점수 풀이, 예시 만들기 | 완성 |
| `docs/examples/` | 엔진이 레시피로 만든 실제 영수증과 설계 꾸러미 | 완성 |
| `src/styles/tokens.css` | 색·글꼴·모션 토큰 (대비 확인함) | 완성 |
| 화면, 배포, 집계 | Astro 화면, Cloudflare 배포, 익명 집계 | `docs/TASKS.md` 순서대로 구현 |

결과물이 어떻게 생겼는지 먼저 보려면 `docs/examples/lunch-page.md`를 여세요.

## 시작하기

1. 준비물: [Node.js](https://nodejs.org/ko) 22.18 이상 (24 LTS 권장), Git, Claude Code.
2. 압축을 풀고 터미널에서 이 폴더로 이동합니다.
3. 설치하고 검사합니다. '자료 검사 통과'와 '모든 골든 사례 통과'가 보이고 오류 없이 끝나면 정상입니다.

   ```bash
   npm install
   npm run check
   ```

4. Git 저장소로 만듭니다.

   ```bash
   git init
   git add -A
   git commit -m "코드쇼퍼 개발 꾸러미"
   ```

5. `claude`를 실행하고 아래 첫 지시문을 붙여 넣습니다.

   ```text
   CLAUDE.md와 docs 폴더의 문서를 읽고 이 프로젝트를 10줄로 요약해 줘.
   이해가 안 되거나 문서끼리 어긋나는 곳이 있으면 먼저 물어봐. 코드는 아직 고치지 마.
   ```

6. 질문에 답한 뒤 `/next-task`를 입력합니다. 작업 하나가 끝날 때마다 Claude Code가 확인 방법을 알려 줍니다. 직접 열어 보고, 괜찮으면 다시 `/next-task`.

## 사람이 해야 할 일

Claude Code가 대신할 수 없는 일입니다. 자세한 내용은 `docs/TASKS.md`의 H·C 작업에 있습니다.

| 언제 | 할 일 |
|---|---|
| 미리 보기 배포 전 (T21) | Cloudflare 계정(무료 플랜), GitHub 공개 저장소 만들기 |
| 정식 출시 전 | 진열 상품 16개를 공식 문서와 대조하고 `needsReview`를 false로 (`npm run validate:release`가 막고 있음) |
| 정식 출시 전 | 개인정보 처리방침·이용 안내 최종 문구, 교원 겸직 신고, '학원' 명칭, 국외 이전 고지 확인 |
| 이름 확정 전 | KIPRIS 상표 검색, 도메인 확인 |
| 정식 출시 전 | 교사 5명 관찰 시험 |
| 언제든 | 진열 상품·개념 카드·에러 안내 늘리기 (`/add-product`로 초안, 사람이 확인) |

## 명령

| 명령 | 하는 일 |
|---|---|
| `npm run check` | 자료 검사 + 골든 사례 + 타입 검사 |
| `npm run validate:release` | 배포용 자료 검사 |
| `npm run golden` | 추천 회귀 검사 |
| `npm run explain -- case-01` | 사례 하나의 칸별 점수 풀이 |
| `npm run examples` | 영수증·꾸러미 예시 다시 만들기 |
