# 컨셉 (v5 바이브코딩 재료 쇼핑몰)

정본은 `docs/review/v5/brief.md`(2026-10-14 소유자 결정)이고, 이 문서는 그것을 짧게 줄인 것이다. v1~v4의 세계관(기사·지도·단계·설계도)은 버렸고 옛 문서는 `docs/archive/v4/docs/CONCEPT.md`에 있다.

## 1. 한 줄

**코드쇼퍼 = 바이브코딩 재료 쇼핑몰.** 앱을 만들 때 쓸 수 있는 공개 재료를 카테고리별로 진열하고, 이용자가 쇼핑하듯 둘러보며 장바구니에 담는다. 결제 대신 **0원 영수증**과 **재료 목록 .md**를 받아 자기 AI에게 준다.

- 소개 한 줄: "폰트·API·MCP·템플릿까지, 앱 만들 재료를 담아 내 AI에게 건넨다."
- 사이트는 AI를 부르지 않는다. 추천·호환성 판단·단계 안내는 하지 않는다(AI가 더 잘 설명한다). 소유자는 자료만 갱신한다(`npm run import`).

## 3. 화면 (쇼핑몰)

- **머리줄:** 로고 · 검색창 · 카테고리 메뉴(모든 대분류·소분류) · 장바구니(담은 개수 배지). 휴대폰은 메뉴 · 로고 · 검색 아이콘 · 장바구니.
- **홈:** 한 줄 소개 + 검색 + 대분류 타일 + 기획전(인기 폰트, 스타 많은 템플릿, 인기 MCP 서버, AI API, 인증 없이 쓰는 API, 최근 갱신).
- **목록 `/c/<대분류>/<소분류>`:** 상품 격자(휴대폰 2열 · 태블릿 3열 · PC 4~5열), 정렬(인기·이름·최근), 쪽 번호(주소에 `?page=`). 거르기는 S3.
- **상품 상세 `/item?id=`:** 큰 미리 보기, 정보 표, 쓰는 법, 관련 상품, [장바구니에 담기] + 메모(어디에 어떻게 쓸지).
- **장바구니(S2):** 머리줄 장바구니를 누르면 오른쪽 서랍(대분류별 줄, 메모 고치기·빼기, 합계 0원, [계산하기]), `/cart`는 만들 앱 한 줄·설치 명령 한꺼번에 복사·공유 링크(재료 id만)·모두 비우기·주문 요약. 카드 [담기] 뒤 작은 창(메모 선택·장바구니 보기), 이미 담은 카드를 다시 누르면 서랍이 그 줄을 연다.
- **계산 → 0원 영수증(`/receipt?id=`, 번호·때·대분류별 개수) → .md 받기(`codeshopper-<yyyymmdd-hhmm>.md`)·복사, 지난 영수증 `/receipts`(최근 30장).** .md는 AI에게 하는 머리말(이 재료로 만들어 줘, 라이선스, 비밀 값은 서버 쪽) · 만들 앱 · 대분류별 재료(이름·공식 주소·라이선스·출처·설치·조각·내 메모) · 라이선스 주의.
- **홈 더하기(brief 7절):** 최근 본 재료(20개), 스타터 키트(`data/kits.json`: 랜딩 페이지·AI 챗봇·학교 정보 앱·대시보드, 한 번에 담기).
- **어려운 말:** 글을 고르면 풀이(드래그 풀이) + `/terms` 용어 사전.

## 4. 디자인

- 대형 쇼핑·마켓 플랫폼의 목록·상세·장바구니 패턴과 공개 디자인 시스템을 참고한 깔끔한 커머스 UI.
- 색은 장바구니 로고에서: 파랑 `#0364F5` 주색, 남색 `#142A4C` 글자, 대분류 강조색은 로고 카드 색(디자인 코랄 · AI 확장 파랑 · API 보라 · 오픈소스 초록 · 데이터셋 노랑 · 템플릿 남색). 낮·밤 모드. 토큰은 `src/styles/tokens.css`.
- 반응형 600 미만 · 600~1023 · 1024~1439 · 1440 이상, 최대 폭 1440. PC 첫 화면에 검색·카테고리·상품 첫 줄.
- 문체는 다체, 표준 용어·외래어 그대로 (`.claude/rules/copy.md`).
- 사람 캐릭터 그림은 쓰지 않는다. 로고는 소유자가 준 장바구니 로고 하나.
