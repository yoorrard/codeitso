# 디자인 의뢰서 (Design Brief)

코드쇼퍼 화면을 만드는 사람(과 에이전트)이 먼저 읽는 짧은 안내다. 정본은 `docs/CONCEPT.md`(D56)이고, 이 문서는 어디를 보면 되는지와 피할 것 목록만 둔다. `frontend-design` 스킬은 CONCEPT와 이 의뢰서를 의뢰인의 말로 본다: **여기 적힌 방향이 일반 디자인 지침보다 앞선다.** 문서끼리 어긋나면 PRD > CONCEPT > 이 문서 순으로 따른다.

| 알고 싶은 것 | 볼 곳 |

## 2. 누구를 위한 화면인가

- 대상: AI 채팅은 써 봤지만 앱 만들기는 막막한 교사·직장인·대학생. 겁먹지 않게, 그러나 유치하지 않게.
- 화면의 일: 지금 어디에 있고, 다음에 무엇을 누르면 되는지 한눈에. 재미는 진행을 돕는 데 쓴다 (순위표·벌점·시간 압박 없음).
- 인상: 차분하고 정교한 고급 전용차와 지도 앱. 장난감이나 테마파크처럼 보이지 않는다.

## 3. 피할 것 (싸 보이는 신호와 생성형 기본값)

CONCEPT 5.9절에 옛 의뢰서의 '생성형 기본값처럼 보이는 것' 목록을 합쳤다. 둘이 다르면 CONCEPT를 따른다.

- **사람과 장식**: 귀여운 사람 캐릭터와 마스코트, 이모지·Fluent 3D 그림 문자, 색종이, 축하 팡파르.
- **색과 바탕**: 따뜻한 크림색 바탕 + 세리프 제목 + 테라코타 강조, 그라데이션 장식(지도 밖), 유리 흐림, 금색 큰 채움 버튼, 남색 두꺼운 머리말, 노란색이 주인공인 화면(카카오 T처럼 보임), 검정·흰색만 쓰는 화면(우버 복제처럼 보임), 원색 하늘색 바다와 형광 연두 잔디의 하이퍼캐주얼 색.
- **글자**: 대문자 꼬리표, 기울임 강조, 제목 속 한 단어만 색 바꾸기, 버튼 글 끝의 '→', 세리프·손글씨·둥근 게임 제목 글꼴.
- **카드와 움직임**: 모든 것을 같은 둥근 카드에 넣고 같은 그림자 깔기, 카드마다 hover 확대, 섹션마다 아래에서 떠오르는 등장 효과, 끝없이 도는 반복, 지금 할 일과 상관없는 장식 애니메이션.
- **정보 표시**: LED 전광판, 의미 없는 km 숫자, 별 난이도, "인기"·"베스트"·"○명이 보고 있어요"·남은 시간 세기 같은 꼬리표.
- **그림**: 빛 방향이 서로 다른 그림, 한 목록 안에 렌더와 평면 그림이 섞이는 것, 지도 위의 3/4 시점 그림, 저폴리 점토 질감, 만화 외곽선, 그림 속 글자·숫자·로고, 실제 차종·실제 건물·실제 회사 로고와 지도, 실제 지하철 노선 색 체계, 남의 캐릭터를 닮은 그림.
- **조작**: 입력 줄처럼 생겼는데 글을 넣을 수 없는 버튼.
