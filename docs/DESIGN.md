# 디자인 의뢰서 (Design Brief)

코드쇼퍼 화면을 만드는 사람(과 에이전트)이 먼저 읽는 문서다. `frontend-design` 스킬은 이 의뢰서를 의뢰인의 말로 본다: **여기 적힌 방향이 일반 디자인 지침보다 앞선다.** 화면별 내용은 `docs/UX.md`, 값은 `src/styles/tokens.css`.

## 1. 한 문장

> 금빛 배지를 단 기사님이 코딩이 처음인 어른을 남색 차에 태우고, **노선도 보드게임**처럼 정류장 다섯 곳을 돌며 모신다. 손님은 마지막에 감열지 영수증과 도장을 받고 내린다.

- 대상: AI 채팅은 써 봤지만 앱 만들기는 막막한 교사·직장인·대학생. 겁먹지 않게, 그러나 유치하지 않게.
- 화면의 일: 지금 어디에 있고, 다음에 무엇을 누르면 되는지 한눈에. 재미는 진행을 돕는 데 쓴다 (순위표·벌점·시간 압박 없음).

## 2. 세계관과 소재 (여기서 시각 선택이 나온다)

| 소재 | 화면에서 |
|---|---|
| 모범택시·기사 제복 (남색, 금색 줄, 흰 장갑) | 브랜드 색 남색 + 금색. 금색은 '중요한 것 하나'에만 |
| 노선도·지하철 노선 | 맨 위 노선 띠: 굵은 선 위 정류장 핀 다섯, 지나온 구간은 칠해짐 |
| 행선지 전광판 (버스·택시 LED) | 남색 바탕 + 금색 고정폭 글자로 "이번 정류장: 장보기" — 게임 화면의 상황판 역할 |
| 주행 거리계 | 숫자 기둥이 굴러가는 km 계기판 = 진행 표시 (점수 아님) |
| 승차권·스탬프 투어 도장 | 정류장을 마치면 도장. 도장판은 '내 여행 기록' |
| 감열지 영수증 | 흰 종이, 고정폭 글자, 아래 톱니 가장자리, 빨간 둥근 도장 "코드쇼퍼 · 요금 0원" |
| 신호등 | 재확인의 충돌 = 빨간불, 해결 = 초록불, 모두 초록이면 "영수증 뽑기"가 켜진다 |
| 장바구니·진열대 | 장보기 칸 = 인벤토리 칸, 상품 = 진열된 카드 |

실제 회사 로고·차 브랜드·지하철 노선 색 체계를 베끼지 않는다. 남의 캐릭터를 닮게 그리지 않는다.

## 3. 색

기사님 그림에서 뽑았다. 값과 대비는 `src/styles/tokens.css`가 정본이다 (T02에서 이 표대로 바꾸고 대비 검사를 돌린다).

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--paper` | #F2F5FA | 기본 바탕 (옅은 지도 종이, 차가운 쪽) |
| `--card` | #FFFFFF | 카드·창 바탕 |
| `--receipt` | #FFFFFF | 영수증 종이 |
| `--ink` | #16213F | 기본 글자 (남색 먹). paper 14.5:1 |
| `--ink-soft` | #4B5674 | 보조 글자·입력 칸 테두리. paper 6.7:1 |
| `--line` | #D3DBE8 | 장식 선만 |
| `--navy` | #1E2C58 | 제복 남색: 머리말, 전광판, 차 몸체, 주 버튼 바탕 |
| `--navy-deep` | #121B3A | 도로, 어두운 면 |
| `--taxi` (금색) | #F5B700 | 배지 금색: 강조 채움(위 글자 `--ink`), 남색 위 글자(7.5:1). 밝은 바탕 위 글자로는 쓰지 않는다 |
| `--gold-soft` | #FFF1C2 | 추천 표시 바탕, 지나온 노선 구간 |
| `--teal` | #0A7568 (T02에서 4.5:1 이상으로 확정) | 기사님 옷깃 핀: 현재 위치·지도 핀 |
| `--go` / `--stop` / `--caution` | 기존 값 유지 | 신호: 해결·충돌·경고 (늘 아이콘 + 글과 함께) |

- 밝은 바탕 위 금색 채움은 한 화면에 하나: 그 화면의 주 버튼 또는 가장 중요한 숫자. 머리말 전광판의 금색 글자는 세지 않는다.
- 그림자는 남색 기반 한 가지(`--shadow`). 카드마다 같은 회색 그림자를 깔지 않는다.

## 4. 글꼴

- 본문·제목: **Pretendard** (OFL, 동적 하위 집합을 직접 싣는다). 제목은 굵기 800, 자간 -0.02em, 짧게. 본문 16px 이상, 줄 간격 1.6, `word-break: keep-all`.
- 영수증·전광판·계기판 숫자: **영수증 글꼴** — D2Coding(OFL)에서 필요한 글자만 잘라 이름을 바꾼 고정폭 글꼴 (`'CC Receipt'`, 유니코드 범위별 조각). 숫자는 `tabular-nums`.
- 기울임 강조, 대문자 꼬리표, 제목 속 한 단어만 색 바꾸기는 쓰지 않는다.

## 5. 화면 뼈대 (휴대폰 360px)

```text
┌──────────────────────────────┐
│ ●─●─◉─○─○   노선 띠 (정류장 5) │  ← 지나온 구간 금빛, 차 아이콘이 지금 정류장
│ [이번 정류장: 장보기]  12km ⚙ │  ← 전광판(남색+금색 글자), 주행 거리, 설정
├──────────────────────────────┤
│                              │
│      무대 (질문 카드 /        │  ← 화면마다 한 가지 일
│      진열대 / 신호등 판 /     │
│      영수증 프린터)           │
│                              │
│ 🧑‍✈️ 말풍선(필요할 때만)        │  ← 기사님은 왼쪽 아래에서 고개를 내민다
├──────────────────────────────┤
│ [ 주 버튼 (금색) ]      [사전] │  ← 엄지 자리. 사전 버튼은 늘 오른쪽 아래
└──────────────────────────────┘
```

- 정렬은 왼쪽. 가운데 정렬은 홈 첫 장면과 영수증만.
- 넓은 화면(768px 이상)은 무대를 720px 안쪽에 두고, 노선 띠를 길게 펼친다. 1280px에서는 사전 옆 창이 오른쪽에 붙는다.

## 6. 기사님 (마스코트)

- 원본: `src/assets/mascot/chauffeur-wave.webp` (소유자가 준 그림 한 장, 손 흔들며 윙크). 다른 자세는 `docs/HUMAN.md` M02로 요청했다. 받기 전에는 이 한 장을 쓴다.
- 나오는 곳: 홈(크게, 차 문이 열리며), 정류장 도착 순간(작게, 말풍선과 함께), 재확인을 마칠 때, 계산대(축하). 그 밖에는 전광판 옆 작은 얼굴만. **모든 화면에 크게 띄우지 않는다.**
- 말: 해요체, 운전기사가 모시는 말투, 한 번에 두 문장·문장당 40자 안쪽. 말풍선은 글이므로 화면 낭독기가 읽는다 (그림은 `alt=""` 장식 + 말풍선 글).
- 움직임: 등장 때 한 번 통통, 누르면 살짝 찌그러짐, 도착하면 한 번 깡총. 끝없이 흔들지 않는다.
- 그림을 고치거나 새로 그리지 않는다. 자르기·크기 바꾸기·알파 정리·(소유자 동의 뒤) 흔드는 팔 조각 내기만 한다.

## 7. 게임 요소

| 요소 | 규칙 |
|---|---|
| 노선도·정류장 | 정류장 다섯. 갈 수 있는 곳만 누를 수 있고, 잠긴 곳은 자물쇠 + 이유 글. 도착하면 핀이 톡 튀고 구간이 금빛으로 칠해진다 |
| 도장 | 정류장을 마칠 때 하나 (첫 수업·인터뷰·장보기·재확인·계산대), 필수 개념을 다 읽으면 하나, 확인 문제 정답마다 작은 도장. 처음 받을 때만 찍히는 장면 |
| 주행 거리 | 지금 상태에서 계산한다 (답한 질문, 채운 칸, 해결한 충돌, 영수증, 읽은 개념). 늘어나기만 하는 점수가 아니라 '얼마나 왔나'. 다른 사람과 비교하지 않는다 |
| 신호등 | 충돌마다 하나. 바꾸기 또는 그대로 두기를 고르면 초록. 모두 초록이면 "영수증 뽑기" 버튼이 켜진다 |
| 영수증 | 프린터에서 위에서 아래로 뽑히고, 도장이 쾅. 색종이는 한 번, 1.2초 |
| 3D 느낌 | CSS 3D(원근 도로, 카드 뒤집기, 차 문, 영수증 종이 말림)와 Fluent 3D 그림 문자 아이콘. WebGL은 기본으로 쓰지 않는다 (1단계 선택 과제 T16b의 시험을 통과할 때만 홈에 넣는다, D26) |
| 효과음 | 기본 꺼짐. 켜면 짧은 합성음 (톡, 뿅, 딩동, 삐빅, 쿵, 드르륵, 빰빠밤). 소리만으로 뜻을 전하지 않는다 |

## 8. 아이콘과 그림

- 정류장·칸·상품 분류·보상: Microsoft Fluent Emoji 3D (MIT) 128px webp. 예: 첫 수업 🎓, 인터뷰 🗺️, 장보기 🛒, 재확인 🚦, 계산대 🧾 / 화면 💻, 저장 🗃️, 로그인 🔑, 외부 데이터 📡, 알림 🔔, 배포·공유 🚀. 받은 목록은 `public/emoji/SOURCE.md` (고정 커밋 1ffb34c, 30개). 더 필요하면 `scripts/assets/fetch-emoji.ts` 목록에 더한다.
- UI 아이콘(닫기, 복사, 뒤로, 소리, 설정): Phosphor (MIT) duotone 한 가지 모양, 빌드 때 인라인 SVG. 쓰는 아이콘은 `src/lib/icons.ts`에 등록한다 (D38).
- 인터뷰 그림 보기·개념 그림·노선도·차: 직접 그린 단순한 SVG (`svg-illustrator`), 토큰 색, 선 굵기 4, 둥근 끝.
- 크레딧: `/about/credits`에 모든 외부 자산의 라이선스를 적는다 (Fluent MIT, Phosphor MIT, Pretendard·D2Coding OFL, canvas-confetti ISC, ZzFX MIT).

## 9. 모션 원칙 (자세한 표는 `docs/UX.md` 4절)

- 한 화면에 '게임 순간'은 하나. 나머지 조작은 빠르고 조용하게 (UI 조작 300ms 안쪽).
- 모션 하나 1초 안쪽, 공들인 장면 3초 이하, 누르면 끝. 동작 줄이기면 이동 없이 결과만 (짧은 페이드는 남김).
- 곡선은 강한 ease-out, 화면 위 이동은 ease-in-out, 도장·도착은 살짝 튀는 스프링(`linear()`), 같은 값은 토큰으로.

## 10. 피할 것 (생성형 기본값처럼 보이는 것)

- 따뜻한 크림색 바탕 + 세리프 제목 + 테라코타 강조, 모든 것을 똑같은 둥근 카드에 넣고 같은 그림자 깔기, 그라데이션 장식, 대문자 꼬리표, 버튼 글자 끝 '→'.
- 섹션마다 아래에서 떠오르는 등장 효과, 카드마다 hover 확대.
- 지금 할 일과 상관없는 장식 애니메이션, 끝없이 도는 반복.
