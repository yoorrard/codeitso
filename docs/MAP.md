# 길 지도 명세 (T28)

`docs/CONCEPT.md` 5.3·5.5·5.6·6절·7절·9(a)의 지도를 코드로 옮길 때 지키는 약속이다. 땅 판·표지 묶음·지도 모형·지도 섬이 이 문서 하나를 보고 따로 만들어져도 맞물리게 한다. 어긋나면 CONCEPT가 이긴다.

## 1. 좌표

- **지도 세계**: `viewBox="0 0 432 240"` (24px 격자 18×10칸). 휴대폰 360px에서 배율이 0.83~1.1이 되도록 정한 크기다.
- 지도 띠는 `preserveAspectRatio="xMidYMid slice"`로 그린다. 띠 높이(만들 앱 정하기 160, 도구 고르기·도구끼리 맞춰 보기 220, 설계도 받기 260, 768px 이상이고 키 700 이상이면 320, 키가 700 밑인 화면은 모두 160)에 따라 위아래나 양옆이 잘린다. 160 밑으로는 줄이지 않는다: 안전 구역이 들어가도록 판이 작아져 이름표가 14px 밑으로 내려간다. 내 AI 써 보기에는 지도가 없다.
- **안전 구역**: 길·마디·이름표·빈 터·집·표지는 모두 **x 60~372, y 32~208** 안에 둔다. 위 띠 높이 어느 것에서도 잘리지 않는 구역이다 (360×264에서 양옆 52씩, 360×160에서 위아래 24씩, 768×320에서 위아래 30씩 잘린다).
- 넓은 화면(나눈 화면의 오른쪽 지도)은 `xMidYMid meet`로 세계 전체를 보이고, 남는 자리는 땅 판이 채운다. 그래서 땅 판은 세계보다 크다 (2절).
- 길은 45°·90°만 쓴다. 굽는 곳은 반지름 12로 둥글게, 선 끝과 이음은 둥글게.
- 빛은 왼쪽 위에서 온다. 그림자는 오른쪽 아래로 (2, 3) 옮긴 같은 모양을 `--map-shadow`로 칠한다 (흐림 없음).

## 2. 땅 판 `src/assets/map/land.svg`

- `scripts/assets/make-map.ts`가 고정 시드로 만든다 (`npm run map`). 손으로 고치지 않는다.
- 겉 요소: `<svg xmlns="http://www.w3.org/2000/svg" x="-432" y="-240" width="1296" height="720" viewBox="0 0 1296 720" aria-hidden="true" focusable="false">`. 지도 세계(0,0)는 땅 판의 (432, 240)이다.
- 색은 파일에 쓰지 않는다. 요소마다 아래 클래스만 붙이고, 칠은 `src/styles/map.css`가 토큰으로 한다.

| `ml-block` | 90° 격자 블록 (둥근 모서리 6) | `--map-block` |
| `ml-street` | 꾸밈 길 (선, 등급별 굵기 10·7·5·3) | `--map-road` 선, 그 아래 `ml-street-edge`가 `--map-road-edge`로 2 더 굵게 |

- **안전 구역 안은 조용하게**: 지도 세계의 안전 구역(땅 판 좌표 x 492~804, y 272~448)에는 블록을 두지 않거나 아주 작게 둔다. 내 길이 꾸밈 길·블록과 섞여 읽히지 않으면 안 된다. 강과 공원은 안전 구역 밖에 둔다. 안전 구역을 지나도 되는 것은 옅은 오솔길뿐이다.

- **띠 아래 이음매**(세계 y 208~240): 시트가 띠 아래를 덮고 둥근 모서리로 깎으므로 큰길(1·2등급)과 45° 큰길을 두지 않는다. 세로 길은 아래 변으로 들어오지 않고, 45° 큰길 아래 토막은 강 아래 길에서 시작한다. `make-map.ts`가 휴대폰 띠가 보이는 가로 범위(세계 x -40~472)에서 검사한다.
- 크기: gzip 24KB 이하. 좌표는 정수로 쓴다.

## 4. 지도 모형 `src/lib/map/model.ts`

순수 함수다 (DOM·저장소 없음, 같은 입력이면 같은 출력, 시험 있음). 계산은 `evaluate()` 결과를 읽기만 한다.

```ts
mapModel(r: EngineResult, opts?: { focus?: string /* 지금 여는 칸 id */; traffic?: boolean /* 도구끼리 맞춰 보기: 교통 색 */; arrived?: boolean }): MapModel
layoutMap(input: MapInput): MapModel   // 시험이 32가지 기능 조합을 바로 넣어 볼 수 있게 나눈 안쪽 함수
```

- **점**: 출발(84, 168) → 마디(칸 순서, `r.slots`의 순서 그대로) → 빈 터(가운데 336, 84). 길은 한 벌로 고정이다: 왼쪽 세로 → 위 줄(y 72) → 가운데 세로(x 216) → 아래 줄(y 168) → 오른쪽 세로 → 빈 터 아래 가장자리. 마디 1~6개는 마디 수마다 정한 자리 한 벌(`LAYOUTS`)에 앉는다. 왼쪽 세로에는 마디를 두지 않는다(출발에 선 차의 자리). 자리는 시험의 모든 기능 조합·상태가 겹침 없이 통과하는 것 가운데, 고를 때마다 차가 앞으로 가는 횟수가 많고 마디 사이가 고른 것을 골랐다 (D68).
- **자리 잡는 차례**: 굴 → 차 → 이름표 → 표지. 뒤의 것이 앞의 것을 비킨다. 굴은 고른 것과 상관없이 정해지므로 차가 움직여도 제자리다.
- **마디 상태**: `ghost`(아직) / `open`(지금 여는 칸인데 아직 고르지 않음) / `picked`(고름) / `later`(나중으로 미룸: 본선 자리에서 비켜난 가지 끝, 점선 회색 가지 + 고깔. 위 줄은 아래로, 아래 줄은 위로, 가운데 세로는 ∩ 안쪽인 왼쪽으로 36) / `jam`(풀지 않은 막힌 곳이 붙음) / `slow`(그대로 가기로 둔 막힌 곳이 붙음). `traffic`이 아니면 `jam`·`slow`는 쓰지 않는다.
- **지금 여는 칸**: 상태와 따로 `focus: { id, x, y, r: 16 } | null`로 낸다. 선 3의 고리를 그리면 바깥 끝(17.5)이 마디 상자 반쪽 16 + 이름표 띄움 2 안에 든다. 고른 칸을 다시 열면 `picked` + 고리다. 모양을 1.15배로 키우지 않는다.
- **길**: 이웃한 두 점 사이 토막마다 `d`(45°·90°, 굽는 곳 반지름 12)와 상태 `ghost`/`built`/`jam`/`slow`/`later`. 앞 점까지 다 됐고 뒤 점이 고름이면 `built`. 본선 전체를 잇는 `routeD`와 그 길이 `routeLength`도 낸다 (차가 따라가는 `offset-path`).
- **이름표**: 마디마다 기능 이름(칸의 `label`), 출발('출발'), 빈 터(앱 종류 이름, 없으면 '목적지'). 글자 크기 17(세계 단위), 굵기 700. 위 줄은 마디 위에, 아래 줄은 마디 아래에, 가운데 세로는 왼쪽에. 빈 터 이름은 터 위에 두되 깃발을 비키고, 넓으면 깃발 왼쪽에 끝을 맞춘다. 이름표 상자는 서로, 그리고 마디·빈 터·깃발·집·굴·차·표지와 겹치지 않고, 길(바깥 선 반쪽 4 + 띄움 2)에도 앉지 않는다.
- **표지**: 막힌 곳의 `anchorSlot` 마디에 하나. 네 귀퉁이(±14, ±14)부터, 막히면 길과 직각인 변 가운데(18)에 붙는다. 종류는 충돌 id로 고른다: `paid-on-free` → `toll`, 빈 칸 → `gap`, `key-in-static-page`·`key-on-public-host` → `lock`, `personal-server` → `globe`, 그 밖 → `alert`. 그대로 가기로 둔 것은 `question`. `anchorSlot`이 없거나 붙을 자리가 없으면 '길 전체' 표지 하나에 모은다: 출발 고리 오른쪽 위 귀퉁이(+12, −12), 막히면 오른쪽 아래(+12, +12), 그다음 출발 오른쪽(+36, 0). 여럿이면 `countAt`(표지 가운데 + (10, 9), 반지름 7)을 내고 `box`가 개수 동그라미까지 품는다.
- **굴**: 중간 서버를 고르면 외부 데이터 다음 토막(없으면 배포·공유 앞 토막부터)의 곧은 곳에, 키가 드러나는 막힌 곳이면 점선 굴(`ghost`). `x, y`는 둔덕 가운데, `angle` 0이면 `mk-tunnel`(32×20), 90이면 `mk-tunnel-v`(20×32)를 돌리지 않고 쓴다. `sign`은 늘 똑바로 세우는 `mk-tunnel-sign`(16×16)의 가운데다(가로 굴 (+12, −12), 세로 굴 (+14, −8)). `box`는 둔덕과 표지를 함께 감싼다. 차가 먼저 서 보는 자리는 될 수 있으면 비워 둔다.
- **차**: `x, y, angle`은 `routeD` 위 `dist` 자리의 점과 그 자리의 길 방향 그대로다(`offset-distance: dist` + `offset-rotate: auto`와 같은 값, 굽는 곳이면 호 위의 점과 접선). 그래서 S3·S5는 `offset-distance`만 바꾸면 된다. 서는 곳: 출발부터 이어서 끝난 마지막 점 앞(마디 반쪽 16 + 띄움 4 + 차 길이의 반 18 = 38), 앞이 좁으면 뒤. 출발이면 44(출발 고리와 '길 전체' 표지 자리를 비킴), 도착이면 앞이 빈 터 가장자리에서 4 떨어진 곳(길 끝에서 26). 마디·출발·빈 터·굴·고깔과는 돌린 차(36×18) 기준으로 4 띄우고, 빈 곳을 2씩 옮겨 찾는다. 출발부터 지금까지 점마다 차례로 자리를 잡아 고를수록 뒤로 가지 않는다(마디 4개까지는 늘 앞으로, 5·6개는 촘촘한 두 마디 사이에서 한 마디 뒤에 남을 수 있다). `box`는 돌린 차를 감싼 상자다(이름표·표지가 비킨다). 그리는 쪽: `mk-car-top`·`mk-car-lights`를 `x=-18 y=-9`, `transform="translate(x y) rotate(angle)"`로 놓고, 그림자는 돌지 않는 부모의 필터로 (5절).
- **빈 터**: `state`는 `bare`(맨땅, 앱 종류를 아직 모름) / `outline`(파란 점선 청사진) / `drawn`(실선 청사진, 도착). 깃발은 밑동 (12, 22)이 왼쪽 위 말뚝 (6, 6)에 꽂힌다: `flag = (터.x − 6, 터.y − 16)`. 집은 깃발 왼쪽 2에 붙인다(위 오른쪽 굽는 곳을 도는 차와 띄움이 남는다).
- **그 밖**: 학생 정보(`sensitive.students`)면 저장 마디에 `hatch`(`mk-hatch-ring` 44×44를 가운데에. 고리 바깥 4는 이름표 땅색 테두리가 덮는다), 쓰는 사람(`audience.me` 1채 / `audience.few` 3채 / `audience.public` 골목)은 빈 터 옆, 느낌 답(`q.style`)은 `palette`(clean·cute·calm·bold)로.
- **한 지도의 기호는 12개 이하**: 마디 + 출발 + 빈 터 + 집 + 굴 + 표지. 넘으면 표지를 '길 전체' 하나로 모은다.
- **요약 글**: `role="img"`에 붙일 한 문장. 수와 말은 상태 한 줄(`src/lib/status-line.ts`)과 같은 `progress()`에서 온다: "목적지 체험학습 신청서. 꼭 고를 것이 1개 남았어요. 막힌 곳이 1개 있어요." 만들 앱을 다 정하기 전에는 목적지 한 문장만 쓴다(처음 오면 "목적지를 아직 정하지 않았어요."). 그대로 가기로 둔 막힌 곳은 따로 세지 않는다(상태 한 줄이 '막힌 곳이 없어요'라고 할 때 어긋나지 않게). 문장 틀은 `src/copy/ko.ts`의 `map` 묶음.
- **크기**: gzip 약 6.4KB (엔진·문구·진행 계산은 다른 섬과 나눠 쓰므로 빼고 잰 값). D63의 '약 3KB'는 차 자리·길 비킴·굴 표지 계산을 더하기 전 목표였다.

## 5. 지도 섬 `src/components/MapBoard.tsx`

- 같은 컴포넌트를 섬(`client:*`)으로도, 정적 HTML(지시어 없이)로도 쓴다. 지난 영수증의 미니 지도는 `MapSvg`를 바로 쓴다.
- **싣는 곳** (D68): `map.css`·`map-land.css`는 MapBoard.tsx가 불러온다. 그래서 지도를 그리는 페이지(만들 앱 정하기·도구 고르기·도구끼리 맞춰 보기·설계도 받기·지난 영수증)에만 실린다. 표지 묶음(`MapSprite.astro`)은 `Base.astro`가 지도 띠가 있는 단계에만, 지난 영수증은 페이지가 직접 넣는다.
- **붙기 전에는 땅 판만** (D68): 빌드 때 HTML에는 땅 판만 있고 길·마디·차·이름표는 없다(`role="img"`도 붙은 뒤에). 붙은 뒤 저장된 진행으로 그린 것을 한 묶음(`.mb-live`)으로 `--dur-fade`(150ms, 동작 줄이기에서도 남음) 동안 비친다. 그래서 다시 온 사람이 처음 온 사람의 지도를 잠깐 보는 일이 없다. 지도 섬은 `client:load`로 붙는다(같은 쪽의 다른 섬이 이미 처음부터 자료를 받으므로 더 드는 것은 지도 묶음 약 7.7KB뿐이고, 느린 휴대폰에서 땅만 보이는 틈이 줄어든다). 바깥 svg의 class·`data-palette`는 붙기 전 첫 그림을 빌드 때 HTML과 맞춰야 하므로 처음 온 사람 기준 모형으로 그린다(Preact는 붙일 때 속성 차이를 고치지 않는다).
- **층**: 넓은 땅색 사각형(땅 판 밖, 1944px 넘는 화면) → 땅 판 → 그림자 → 길(밤 빛 → 바깥 → 심) → 굴 → 마디 → 지금 여는 곳 고리 → 빈 터·윤곽·깃발 → 집 → 표지 → 이름표 → 차. 자리는 모두 모형 값 그대로 쓰고 섬에서 고치지 않는다.
- **길** (brief 4.5): 아직 = `--map-ghost` 점 3(대시 0·간격 7, 둥근 끝). 이어짐 = 바깥 8 `--route-outer` + 심 4 `--route-core`. 밤 주행 빛 `--route-halo`는 이어진 길 전체를 path 하나(굵기 14)로 그린다(겹치는 이음매가 두 번 칠해지지 않게, 흐림 필터 없음). 낮에는 투명하고, 교통 정보를 덮은 길에는 두지 않는다. 나중 가지 = `--text-3` 점 3(0 6).
- **교통 정보** (도구끼리 맞춰 보기, `is-traffic`): 바깥 선이 교통 색이고 **심의 무늬로 색 없이도 나뉜다**. 원활 = `--route-smooth` + 같은 초록 실선 심 4(`--route-smooth-core` = `--ok`, 바깥과 한 줄로 보여 두 줄 선로처럼 보이지 않게) · 막힘 = `--route-jam` + 흰 대시 3 3 심(`--route-traffic-core`) · 서행 = `--route-slow` + 둥근 점 0 5 심 3(`--route-slow-core`, 낮 호박 · 밤 어두운 점: 밤에는 `--warn-ink`와 `--warn`이 같은 색이다). 막힘·서행 마디는 같은 색 고리 3과 사고 표시·물음표가 붙는다.
- **마디**: 아직 = 땅색 면 + 점선 `--map-ghost` · 지금 여는 곳인데 빔 = `--surface` 면 + `--text-3` 테두리 · 고름 = `--node-fill` + `--on-node` 그림 · 나중 = 점선 `--text-3`. 모양을 키우지 않는다.
- **지금 여는 곳** (도구 고르기): Shop이 펼친 칸 id를 `src/lib/map/focus.ts`의 `$mapFocus`에 넣고, MapBoard가 읽어 모형의 `focus`로 넘긴다. 고리는 `--you` 선 3, 반지름 16(`m.focus`).
- **차**: `mk-car-top`과 `mk-car-lights`(36×18, `x=-18 y=-9`)를 안쪽 묶음 `.mb-car`에 `translate(x y) rotate(angle)`로 둔다. 그림자는 돌지 않는 바깥 묶음 `.mb-car-wrap`의 필터(`#mb-shade`: 모양 그대로 (2, 3) 옮긴 `--map-shadow`, 흐림 없음)라 차가 어느 쪽을 보든 빛은 왼쪽 위에서 온다. S3·S5는 `.mb-car`에 `offset-path: path(routeD)`를 주면 된다. `mk-car-shadow`는 쓰지 않는다.
- **굴**: `angle` 0이면 `mk-tunnel`, 90이면 `mk-tunnel-v`를 돌리지 않고 놓아 둔덕 그림자가 늘 오른쪽 아래다. 굴 표지 `mk-tunnel-sign`은 `tunnel.sign`에 똑바로. 둔덕 위 길 심(currentColor)은 `--brand-white`. 아직 고르지 않은 굴은 길 방향대로 눕히거나 세운 점선 둥근 네모 + 똑바른 중간 서버 그림.
- **빈 터**: `bare`는 맨땅만, `outline`은 파란 점선(4 3) 청사진, `drawn`은 실선 청사진 + 두루마리. 빈 터는 맨땅이라 그림자를 두지 않는다.
- **표지 개수**: `countAt`에 반지름 10 동그라미(`--text` 면, `--surface` 테두리 1.5)와 글자 15.
- **도착 그림**은 설계도 받기 문이 열려 있을 때만(`r.canIssue`이고 영수증을 받음). 받은 뒤 도구를 바꿔 막힌 곳이 생기면 차는 다시 길 위에 선다.
- `variant="mini"`(64px 썸네일)는 이름표·표지·집·굴·차를 빼고 길과 마디만.
- 길이·색은 토큰만. 움직임(S2·S3·S4·S5·S7)은 W5에서 붙인다. 지금은 정지 그림과 상태 바뀜(동작 줄이기에서도 같은 정보)까지.
- 크기(gzip, `npm run qa:budget`): 섬(MapBoard.tsx + focus.ts만 줄인 것) 8KB 이하, 모형 6.5KB 이하, 빌드한 MapBoard 묶음(섬 + 모형) 14.5KB 이하.
