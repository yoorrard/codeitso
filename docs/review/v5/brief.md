# v5 설계서: 바이브코딩 재료 쇼핑몰 (2026-10-14)

소유자 결정(2026-10-14)으로 컨셉·디자인·기능을 모두 새로 짠다. 이 문서가 CLAUDE.md·`docs/CONCEPT.md`·v2·v3·v4 설계서보다 앞선다. 옛 문서와 어긋나면 이 문서를 따르고 옛 문서를 고치거나 지운다.

## 1. 컨셉

- **코드쇼퍼 = 바이브코딩 재료 쇼핑몰.** 앱을 만들 때 쓸 수 있는 공개 재료를 카테고리별로 진열하고, 이용자가 쇼핑하듯 둘러보며 장바구니에 담는다. 결제 대신 **영수증(0원)**과 **재료 목록 .md 파일**을 받아 자기 AI에게 준다.
- **AI 없이 소유자가 자료만 갱신하면 되는 분야**에 특화한다. 사이트는 AI를 부르지 않는다. 도구 추천·호환성 판단·단계 안내는 하지 않는다(AI가 더 잘 설명한다).
- **버리는 것:** 단계 흐름(만들 앱 정하기·도구 고르기·호환성 확인·설계도 받기), 질문·추천·점수·충돌 엔진, 연결망 설계도, 배포·저장·로그인·알림 도구 카탈로그(변동이 크고 정확하지 않음), 가이드·다음 할 일·AI 설정 파일, 지도·게임 요소 전부.
- **살리는 것:** Astro + Preact 섬 구조, 토큰 체계(새 브랜드 색으로), `store.ts` 한 곳 저장(장바구니로), 영수증(0원·번호·날짜), 드래그 풀이 팝오버와 용어 사전(재료 설명의 어려운 말 풀이), 익명 집계 Worker(이벤트 종류만 바꿈), 주소 바탕·정식 빌드 지킴, 품질 바닥선·검사 하네스, `color.ts`(팔레트 대비 표시).
- **로고:** 소유자가 준 장바구니 로고(`assets-src/brand/logo-cart-source.webp`: 파란 장바구니에 API·MD·차트·아이콘 카드, `</>`, 글자 '코드쇼퍼' 남색+파랑). 옛 기사 로고는 쓰지 않는다. 화면용은 이 원본에서 크기별 PNG/WebP와 파비콘(장바구니만)을 만든다.

## 2. 카테고리 (진열대)

| 대분류 | 소분류(예) | 자료 출처(가져오기 스크립트) |
|---|---|---|
| 디자인 | 폰트 · 색상 팔레트 · 아이콘 묶음 · UI 컴포넌트 라이브러리 · UI/UX 레퍼런스 사이트 · 디자인 톤(스타일) · 일러스트·이미지 소스 | Google Fonts 메타데이터(전체), 한글 폰트(Google Fonts의 korean 하위 집합 + 라이선스가 확인된 공개 한글 폰트), 공개 팔레트 데이터(라이선스 확인), Tailwind·Radix·Open Color 색 체계, Iconify 묶음 목록(전체), 컴포넌트 라이브러리(공식 목록·awesome 목록·GitHub 검색), 레퍼런스 사이트(손으로 고른 목록), 스타일 톤(손으로 쓴 정의 + 로컬 미리 보기) |
| 오픈소스 | GitHub 템플릿·보일러플레이트·라이브러리(주제별) · Hugging Face 모델 · 스페이스 · 데이터셋 | GitHub 검색 API(주제별 별 순), Hugging Face API(작업별 내려받기·좋아요 순) |
| AI 확장 | Agent Skills · MCP 서버 · (규칙 파일 템플릿) | 공개 스킬 저장소와 등록소(anthropics/skills 등), 공식 MCP 등록소 API(전체) |
| API | 공개 API(분야별) · 한국 공공데이터 · 한국 개발자 API(카카오·네이버 등) | public-apis 목록(전체), 공공데이터포털·NEIS 등 공식 목록, 손으로 확인한 국내 API |

- **가져올 수 있는 것은 다 가져온다.** 출처가 목록·API를 주면 개수 제한 없이 끝까지 페이지를 넘겨 받는다(출처가 너무 큰 경우만 상위 기준을 정하고 DECISIONS에 적는다: 예 Hugging Face는 작업별 상위 N, GitHub는 주제별 별 순 상위 N).
- 자료는 `data/catalog/<대분류>/<출처>.json`에 커밋한다. 이름·설명(원문 언어 그대로 + 있으면 한국어 한 줄)·주소·라이선스·인기 지표(별·내려받기)·태그·갱신일·출처를 둔다. 설명을 지어내지 않는다.
- `npm run import`(네트워크 필요)가 다시 받아 같은 자리에 쓴다. 빌드는 네트워크 없이 커밋된 자료만 쓴다. 매주 손으로 돌리는 GitHub Actions 작업 흐름은 나중에.

## 3. 화면 (쇼핑몰)

- **머리줄:** 로고 · 검색창(전체 검색) · 카테고리 메뉴 · 장바구니(담은 개수 배지). 휴대폰은 검색 아이콘 + 메뉴 + 장바구니.
- **홈:** 짧은 소개 한 줄 + 검색 + 대분류 타일 + 기획전(예: "인기 폰트", "많이 담은 MCP", "처음 담기 좋은 API") + 최근 갱신.
- **카테고리 목록 `/c/[대분류]/[소분류]`:** 상품 격자(휴대폰 2열 · 태블릿 3열 · PC 4~5열), 정렬(인기·이름·최근), 거르기(라이선스·태그·인증 방식 등 소분류에 맞게), **페이지네이션**(쪽 번호 + 이전/다음, 주소에 쪽 번호). 카드: 미리 보기, 이름, 출처 배지, 인기 지표, 라이선스, [담기].
- **상품 상세:** 큰 미리 보기, 정보 표(출처·라이선스·인기·갱신일·공식 주소), 쓰는 법 한 덩어리(설치 명령·CSS import·MCP 설정 조각 등 출처가 준 것만), 관련 상품, **[장바구니에 담기] + 메모(선택: 어디에 어떻게 쓸지)**.
- **미리 보기 종류:** 폰트 = 견본 문장(한글·영문), 색상 = 견본 띠와 대비, 아이콘 = 묶음의 대표 아이콘 몇 개, 스타일 톤 = 로컬 CSS로 칠한 작은 화면, 오픈소스 = 저장소 정보 카드(별·언어·라이선스), API = 인증·HTTPS·CORS 배지, 스킬·MCP = 설명과 설정 조각.
- **장바구니:** 오른쪽 서랍 + `/cart` 쪽. 카테고리 안팎에서 여러 개를 담는다. 줄마다 메모 편집, 빼기, 카테고리별 묶음. 프로젝트 메모(선택, 만들 앱 한 줄).
- **계산(체크아웃) → 영수증:** 0원 영수증(번호·날짜·카테고리별 개수) + **[.md 받기] · [복사]**. `.md`에는 머리말(이 재료로 만들어 달라는 AI용 안내), 프로젝트 메모, 카테고리별 항목(이름·주소·라이선스·쓰는 법·내 메모), 라이선스 주의 한 줄. 지난 영수증은 `/receipts`.
- **용어:** 재료 설명 속 어려운 말은 드래그 풀이(있는 기능) + `/terms`.

## 4. 디자인

- 대형 쇼핑·마켓 플랫폼(쿠팡·무신사·29CM·Amazon·Shopify Polaris·Product Hunt·Figma Community·Hugging Face Hub·npm·Envato 등)의 목록·상세·장바구니 패턴과 공개 디자인 시스템(Radix·shadcn/ui·Polaris·Material 3)을 참고해 깔끔한 커머스 UI로 짠다.
- 브랜드 색은 새 로고에서 뽑는다(파랑 주색, 남색 글자, 보라·노랑·코랄·초록은 카테고리 강조색). 토큰만 쓴다. 다크 모드 지원.
- 반응형: <600 · 600~1023 · 1024~1439 · ≥1440, 최대 폭 1440. 스크롤을 줄인다(PC 첫 화면에 검색·카테고리·상품 첫 줄).
- 문체: 다체('~다'), 표준 용어·외래어 그대로(v4 4절).

## 5. 규칙

- 사이트는 AI를 부르지 않는다. 이용자 상태(장바구니·영수증·설정)는 localStorage에만, 저장 코드는 `src/lib/store.ts` 한 곳.
- **외부 자원 예외(이 판에서 바꿈):** 미리 보기를 위해 출처의 공식 CDN에서 글꼴(예: fonts.googleapis.com)과 그림(예: GitHub·Hugging Face 미리 보기 그림)을 **지연 로드**할 수 있다. 추적·광고 스크립트는 여전히 없다. 처리방침에 적는다.
- 상품 사실(라이선스·인증·무료 여부)은 출처 자료 그대로만 쓴다. 출처가 없으면 비운다.
- Cloudflare 정적 파일 한 판 2만 개 한도를 넘지 않게 쪽 수를 설계한다(상세 쪽을 모두 정적으로 만들지, 목록 자료로 그릴지 정한다).
- 첫 화면 JS 100KB(gzip) 이하.

## 7. 범위 넓히기 (소유자 추가 지시, 2026-10-14)

- 소유자가 이름을 댄 출처·항목은 **예시일 뿐**이다. 카테고리마다 쓸 만한 출처를 스스로 찾아 모두 넣는다(GitHub·Hugging Face만이 아니라 GitLab·npm·Kaggle·APIs.guru·여러 MCP 등록소·스킬 등록소·템플릿 갤러리 등).
- **AI API는 빠짐없이:** OpenAI·Anthropic·Google Gemini에서 그치지 않고 공개 API를 내는 AI 회사를 모두 찾는다(언어 모델·이미지·영상·음성·임베딩·검색·추론 호스팅·모델 라우터, 국내 회사 포함).
- 카테고리와 소분류도 필요하면 더한다(예: 데이터셋, 템플릿·스타터, 프롬프트, 3D·애니메이션·소리 에셋, 그라디언트·패턴, 목업).
- 기능도 쇼핑몰에 있으면 좋은 것을 더한다(예: 최근 본 상품, 묶음 기획전(스타터 키트), 장바구니 공유 링크, 설치 명령 한꺼번에 복사).
